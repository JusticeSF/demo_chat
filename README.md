# Учебный чат на Qt5 и CMake
Это учебный проект для изучения:

- C++;
- Qt 5;
- CMake;
- клиент-серверной разработки;
- TCP;
- протоколов;
- сборки проектов;
- документирования.

## Состав проекта

- `common` — общий протокол клиента и сервера;
- `server` — консольный TCP-сервер;
- `client` — графический клиент на Qt Widgets;
- `docs` — документация.

## Сборка

```bash
mkdir build
cd build
cmake ..
make -j$(nproc)
